HIH-PL-uploader

HIH'S PLAYLIST 유튜브 채널의 쇼츠 업로드 자동화 도구

무엇을 하는 도구인가

HIH-PL-uploader는 HIH'S PLAYLIST 유튜브 음악 채널을 운영하기 위해 만든 개인용 스크립트입니다. 채널 소유자가 자신의 컴퓨터에서 직접 실행합니다.

이미 발매한 곡의 앞 60초와 미리 준비해 둔 이미지를 합쳐 세로형 쇼츠 영상을 만들고, 채널 소유자 본인의 유튜브 채널에 비공개 상태로 예약 업로드합니다.

이용 대상은 채널 소유자 한 사람뿐입니다.

다른 사용자를 위한 서비스가 아니며, 회원가입·로그인 기능이 없고, 제3자에게 배포하거나 제공하지 않습니다.

사용하는 Google API

  • YouTube Data API v3 — 영상 업로드 (youtube.upload 범위)

업로드 외의 어떤 기능도 사용하지 않습니다. 시청 기록, 구독 정보, 댓글, 분석 데이터에 접근하지 않습니다.
