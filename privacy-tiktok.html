Privacy Policy

HIH's Playlist Uploader (TikTok integration) · Last updated September 18, 2026

This tool does not collect, store, or transmit any personal data belonging to third parties.

It is a personal script run by the owner of the HIH'S PLAYLIST account on their own computer to publish content to their own TikTok account. It has no server, no other users, and no public sign-up.

1. What this tool does

HIH's Playlist Uploader is a script run by the owner of the HIH'S PLAYLIST TikTok account to publish videos the owner has already created (original AI-composed music videos) to their own account, on a schedule the owner sets.

2. Scopes requested

  • video.publish — permission to directly post a video to the authorized account. This is the only scope this app uses beyond basic account identification needed to complete login.

This app does not read, collect, or store any other TikTok data — not watch history, follower lists, comments, messages, analytics, or any other user's content.

3. Data stored

After authorization, an access token is issued and stored only on the local disk of the computer running the script.

  • Stored in a private folder outside any shared or cloud-synced directory
  • Never transmitted to any external server
  • Never shared or sold to any third party
  • Used solely to publish videos to the owner's own account

4. Third-party sharing

None. This tool communicates only with the TikTok API for the sole purpose of publishing the owner's own content. It contains no advertising, analytics, or tracking.

5. Data retention and deletion

The token is kept locally until the owner deletes it. Deleting the token file revokes access immediately. Access can also be revoked at any time from the TikTok app's own Manage apps and devices settings.

6. Children's privacy

This tool is used by a single account owner and is not directed at children. It does not knowingly collect information from children.

7. Changes

If this policy changes, this page will be updated and the date above revised.
