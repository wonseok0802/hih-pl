채널 소유자 본인이 자신의 컴퓨터에서 실행하는 개인용 도구이며, 서버를 운영하지 않고 다른 사용자를 받지 않습니다.

1. 이 도구가 하는 일

HIH-PL-uploader는 HIH'S PLAYLIST 유튜브 채널의 소유자가 자신의 채널에 영상을 업로드하기 위해 직접 실행하는 스크립트입니다. 이미 발매한 음원의 앞 60초와 미리 준비한 이미지를 합쳐 쇼츠 영상을 만들고, 소유자 본인의 채널에 비공개로 예약 업로드합니다.

2. 요청하는 권한

  • https://www.googleapis.com/auth/youtube.upload
    — 영상을 업로드하는 권한. 이 하나만 요청합니다.

시청 기록, 구독자 목록, 댓글, 채널 분석 데이터, 이메일, 연락처, 파일 등 다른 어떤 정보에도 접근하지 않습니다.

3. 저장되는 정보

Google 인증을 마치면 액세스 토큰과 갱신 토큰이 발급되며, 이는 실행하는 컴퓨터의 로컬 디스크에만 저장됩니다.

  • 저장 위치는 사용자 홈 디렉터리 아래의 비공개 폴더입니다
  • 외부 서버나 클라우드로 전송되지 않습니다
  • 제3자와 공유하거나 판매하지 않습니다
  • 오직 본인 채널에 업로드하는 용도로만 사용됩니다

없습니다. 이 도구는 Google/YouTube API 외에 어떤 외부 서비스와도 통신하지 않으며, 광고·분석·추적 도구를 포함하지 않습니다.

토큰은 사용자가 직접 삭제할 때까지 로컬에 보관됩니다. 토큰 파일을 지우면 즉시 권한이 사라집니다.
